# Code of conduct

## Our standard

This repo hosts training material for a dbt Summit hands-on lab. Interactions here — issues,
discussions, and any conversation about the lab — are expected to be respectful, constructive, and
free of harassment.

Examples of unacceptable behaviour include harassment of any kind, personal or political attacks,
publishing others' private information, and sustained disruption of discussion.

## Scope

This applies to all project spaces, and to anyone representing the project in public spaces.

## Reporting

Report unacceptable behaviour to the owning team via a GitHub issue if it can be discussed openly,
or privately through the [dbt Labs Community Code of Conduct](https://docs.getdbt.com/community/resources/code-of-conduct)
channels if it cannot.

For **security** issues, use [`SECURITY.md`](SECURITY.md) instead — not an issue.
