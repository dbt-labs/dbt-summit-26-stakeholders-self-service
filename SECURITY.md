# Security policy

## Reporting a vulnerability

Please report security issues **privately** so they can be triaged and fixed before public disclosure.

- **dbt Labs responsible disclosure:** [dbt Labs Security Disclosure](https://www.getdbt.com/security/disclosure)
- **GitHub:** If this repository is enabled for them, you may also use [GitHub Security advisories](https://github.com/dbt-labs/dbt-summit-26-stakeholders-self-service/security/advisories/new) for this repo.

Do not open a public issue for an undisclosed security vulnerability.

## Scope

This repo is training material for a dbt Summit 2026 hands-on lab: dbt models, YAML, and Markdown.
It ships no runtime service and no application code. The data is fictional and generated.

If you find a **credential, token, internal hostname, or account identifier** committed anywhere in
this repo or its history, please treat that as a vulnerability and report it privately using the
channel above rather than opening an issue.

## Supported versions

There are no releases. The default branch reflects the lab as taught. Fixes are best-effort; see
the support statement in [`README.md`](README.md).
